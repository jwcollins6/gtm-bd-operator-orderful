# skills/

Agent-facing instructions for this client instance (research a lead, draft outreach,
qualify an inbound contact, check identity, etc.). Mostly empty in the template —
most of these get written per client once onboarding (see `../onboarding/`) has
produced real company understanding, signal, and tech-stack findings to base them
on.

Two exceptions:

- [`account-research-skill.md`](account-research-skill.md) — the *process*
  of doing account research is general enough to hold in the template as-is.
  What differs per client isn't the process, it's the output shape it fills
  in — see `../templates/account-research-brief.md`'s client-specific
  research priorities section.
- [`signal-detection-skill.md`](signal-detection-skill.md) — built for this
  Orderful instance specifically (not template-generic, since it's written
  directly against `../onboarding/signal-inventory-template.md`'s seven
  signals), covering how to actually find candidate accounts before account
  research runs on them.
