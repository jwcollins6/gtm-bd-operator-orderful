# skills/

Agent-facing instructions for this client instance (research a lead, draft outreach,
qualify an inbound contact, check identity, etc.). Mostly empty in the template —
most of these get written per client once onboarding (see `../onboarding/`) has
produced real company understanding, signal, and tech-stack findings to base them
on.

One exception: [`account-research-skill.md`](account-research-skill.md) — the
*process* of doing account research is general enough to hold in the template as-is.
What differs per client isn't the process, it's the output shape it fills in —
see `../templates/account-research-brief.md`'s client-specific research
priorities section.
