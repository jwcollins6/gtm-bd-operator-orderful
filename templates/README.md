# templates/

The shape of artifacts the *running* pipeline produces — research briefs, draft
outreach, qualification notes — as opposed to `../onboarding/`, which holds
templates for the artifacts the *onboarding phase* produces (ICP, personas,
signal inventory), built once per client before either track launches.

Each template here has a general/universal section (same structure for any
client) and a client-specific section, filled in once that client's onboarding
findings exist. The corresponding skill in `../skills/` describes the *process*
for filling one in — this folder just holds the *shape*.
